# AI Market Intelligence

Automated daily AI market intelligence reports combining stock data, news sentiment, GitHub trends, and economic indicators with Claude AI analysis.

## Features

- **Stock Tracking** - Real-time prices for S&P 500, NASDAQ, NVDA, MSFT, AMZN
- **AI News Aggregation** - Top AI/ML headlines from NewsAPI with sentiment analysis
- **GitHub Trends** - Trending AI/ML repositories across Python, Go, Rust, JavaScript
- **Economic Indicators** - Unemployment rate, inflation (CPI) via FRED API
- **Sentiment Analysis** - DistilBERT-powered headline sentiment scoring
- **Claude AI Insights** - Daily market analysis generated by Claude
- **Email Reports** - Automated daily digest delivered via Gmail
- **Streamlit Dashboard** - Interactive UI with today's report, comparisons, 30-day trends, and historical archive
- **Scheduled Execution** - Runs automatically at 8:00 AM daily

## Architecture

```
Data Fetchers (stocks, news, GitHub, economic)
        |
  Sentiment Analysis (DistilBERT)
        |
    Data Processing (aggregate + compare)
        |
   Claude AI Analysis
        |
   Report Generation
        |
  Database Storage (SQLite) + Email (Gmail)
        |
   Streamlit Dashboard
```

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ai-market-intelligence.git
cd ai-market-intelligence
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in your API keys:

- **ANTHROPIC_API_KEY** - Get from [Anthropic Console](https://console.anthropic.com/)
- **NEWSAPI_KEY** - Get from [NewsAPI](https://newsapi.org/)
- **GMAIL_EMAIL** / **GMAIL_APP_PASSWORD** - Your Gmail with [App Password](https://support.google.com/accounts/answer/185833)
- **FRED_API_KEY** (optional) - Get from [FRED](https://fred.stlouisfed.org/docs/api/api_key.html)

### 5. Run the dashboard

```bash
streamlit run app.py
```

## Usage

**Manual run:**

```bash
python -c "from src.data_fetchers import *; print(fetch_stock_prices())"
```

**Scheduled (automatic):**

The system runs automatically at 8:00 AM daily when the scheduler is active.
